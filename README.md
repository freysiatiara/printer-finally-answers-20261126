## The line

> Error 0x47: jammed on page 47 of 48. Not an accident. A choice. Print it yourself.

## How it works

`main.py` (standard library only) writes the line to `/output/entry.txt` with mode `0644`.

```sh
python3 main.py
cat /output/entry.txt
```
